# 1. Target Cloud Provider: Google Cloud Platform (GCP)

Decidimos adotar o Google Cloud Platform (GCP) como provedor de nuvem exclusivo para toda a infraestrutura da solução (rede, compute, banco gerenciado, segredos e IAM). A escolha alinha a arquitetura do desafio técnico à nuvem primária utilizada pela empresa avaliadora, permitindo demonstrar padrões avançados de GCP como Private Service Connect, Cloud NAT, Cloud SQL e Workload Identity.
